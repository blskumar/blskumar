# Hi there

I build tools for testing AI-written software.
I focus on one question: how do you know which AI-generated tests to trust?

## Featured work

### [Verdict AI](https://github.com/blskumar/Verdict-Ai)
A gatekeeper for AI-written test cases. It checks each test case against a
requirements spec and returns one verdict: Approve, Revise, Reject, or Human Review.
- Reads requirements and test cases from PDF, CSV, or JSON.
- A rule engine flags vague wording, compound actions, duplicates, and coverage gaps without calling an LLM.
- A five-role LLM consensus pool reviews the cases the rules cannot settle.
- Stack: Python, FastAPI, Tailwind CSS.

### [Parasoft_Test_Proj](https://github.com/blskumar/Parasoft_Test_Proj)
UI test suite for the ParaBank demo app. It covers login, invalid login cases, and registration.
- Stack: Playwright, Pytest, page-object pattern, Allure reports.

### [PythonQuest](https://github.com/blskumar/PythonQuest)
A gamified Python learning app with onboarding, lessons, quizzes, XP, and streaks.
[Live demo](https://python-quest-tau.vercel.app)
- Stack: Next.js, TypeScript, Supabase.
